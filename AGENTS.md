# actions-experiment

A GitHub Actions experiment repository for trying out various GitHub Actions features and workflows.

## Project Overview

This repository contains experiments with GitHub Actions, including:
- Basic workflow definitions
- Various triggers and events
- Docker-related actions
- Automation scripts

## Repository Structure

- `Dockerfile` - Docker configuration for the action
- `README.md` - Project overview and setup instructions
- `example-file.txt` - Example file demonstrating the experiment
- `info.yaml` - Configuration metadata

## How to Work On This Project

1. **Creating a branch**: Always create a new branch for work (e.g., `git checkout -b feature-name`)

2. **Making changes**: Edit files as needed, following the patterns established in the repo

3. **Committing**: Use descriptive commit messages

4. **Pushing**: Push your branch to the remote repository

5. **Pull Request**: Open a PR against the `master` branch on GitHub

## Development Workflow

```bash
# Create and switch to a new branch
git checkout -b my-feature

# Make changes to files
# ...

# Stage and commit
git add .
git commit -m "Description of changes"

# Push to remote
git push -u origin my-feature

# Then open a PR on GitHub web interface
```
